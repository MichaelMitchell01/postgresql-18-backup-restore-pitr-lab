# PostgreSQL 18.4 Backup, Restore, and PITR Lab

This project demonstrates PostgreSQL DBA recovery operations on Windows 11 using PostgreSQL 18.4 and pgAdmin 4 v9.15.

The lab covers logical backup and restore with pgAdmin, physical base backups with pg_basebackup, WAL archiving, point-in-time recovery, restore validation, and incident-style recovery documentation.

## Skills Demonstrated

- pgAdmin logical backup and restore
- PostgreSQL custom-format backups
- pg_restore validation
- WAL archiving
- pg_basebackup
- pg_verifybackup
- recovery.signal
- restore_command
- recovery_target_time
- PostgreSQL PITR
- Windows-based PostgreSQL administration
- Recovery runbook documentation
